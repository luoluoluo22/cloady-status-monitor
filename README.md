# Cloady JPN1 Status Monitor

24/7 Real-time server status, uptime counter, and performance monitor dashboard deployed on Cloady Japan (JPN1) Free Tier.

## Features
- Real-time Uptime ticker (Days, Hours, Minutes, Seconds)
- CPU Usage, Load Averages and Core information
- Memory usage metrics and visual progress bars
- REST API endpoint `/api/status` for external health probes
- Extremely lightweight (<25MB RAM, Node.js Alpine base)
